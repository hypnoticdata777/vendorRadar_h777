## Publication Boundary

These files intentionally preserve synthesis, methodology, evidence labels, market observations, and open research questions. Raw evidence stays private when it includes signup-email PDFs, screenshots, Reddit usernames, identifying anecdotes, long direct excerpts, account data, or detailed VendorRadar pricing/product execution strategy.
