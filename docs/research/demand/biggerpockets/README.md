# VendorRadar BiggerPockets Mining

This folder contains cleaned, individual BiggerPockets demand-mining teardowns for VendorRadar discovery.

## Files

- `001-maintenance-vendor-bench.md` - maintenance vendor bench, small work orders, emergency readiness, authorization limits, and owner/PM maintenance process.
- `002-repair-proof-owner-verification.md` - repair proof, receipts, photos, owner verification, move-out evidence, and receipt capture.
- `003-maintenance-markups-approval-trust.md` - maintenance markups, approval thresholds, repair fee transparency, and PM fee trust.
- `004-vendor-license-insurance-contractor-authority.md` - vendor license/insurance checks, COI freshness, workers comp, additional insured status, owner-selected vendors, and contractor authority/liability.

## Evidence Boundary

These are synthesis artifacts, not raw evidence dumps. They intentionally omit raw screenshots, member profile details, phone numbers, emails, exact personal contact data, long verbatim excerpts, and sponsored/sidebar material.

Use these individual files as traceable source notes before rolling findings into a higher-level BiggerPockets dossier.
